Code challenge

Test your fundamentals

Pick one answer for each question. Your selection will reveal a short explanation.

1. What does “CPU” stand for?

  • Central Processing Unit
  • Computer Personal Unit
  • Central Program Utility

Correct! The Central Processing Unit executes instructions in a computer.

Not quite. Think about the component that processes instructions.

Not quite. “Utility” is not part of the abbreviation.

2. Which element links an external stylesheet in HTML5?

  • <style src="...">
  • <link rel="stylesheet">
  • <css href="...">

Not quite. The <style> element is used for CSS written inside an HTML document.

Correct! A <link> element in the document head connects an external stylesheet.

Not quite. HTML does not include a <css> element.

3. Which declaration creates a flexible box layout?

  • display: flex;
  • position: flex;
  • float: flex;

Correct! display: flex; establishes a flex formatting context.

Not quite. flex is not a value for the position property.

Not quite. Flexbox is enabled with the display property.

Computer Science trivia

Small facts, big history

The famous computer “bug”

In 1947, a moth was found caught in a relay of the Harvard Mark II computer and recorded in the team’s logbook.

Building blocks of the web

HTML stands for HyperText Markup Language, while CSS stands for Cascading Style Sheets—the two technologies used to build this website.

The creator of HTML

Tim Berners-Lee created the first version of HTML in 1991.
